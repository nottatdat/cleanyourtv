# Stock launcher: com.google.android.apps.tv.launcherx (setupwraith's RecoveryActivity also claims HOME,
# as on the Chromecast with Google TV). No Live TV app and no tuner; it has one HDMI out.
#
# Known quirks on this firmware:
# - Wireless debugging on, port 5555 answered straight away; accept "Allow USB debugging?" once.
# - com.google.android.tvrecommendations and com.google.android.apps.education.cast2class ship
#   disabled at the factory. Don't add them to a restore list.
# - Disabling dreamx leaves screensaver_components pointing at it. Point it at another screensaver.
# - The remote (Vendor_18d1_Product_9451.kl) sends BUTTON_3 for YouTube, BUTTON_4 for Netflix and MACRO_1
#   for the star button; launcherx handles all three, so they go dead once it is disabled. Install with
#   APP_KEY_SERVICE=1 and map them in config.xml app_buttons.
# - Animation scales were set to 0.0 (window, transition, animator) for a snappier UI:
#   settings put global window_animation_scale 0.0; settings put global transition_animation_scale 0.0;
#   settings put global animator_duration_scale 0.0. tools/restore.sh puts all three back to 1.0x.
#

# (com.google.android.apps.mediashell), phone remote (com.google.android.tv.remote.service),
